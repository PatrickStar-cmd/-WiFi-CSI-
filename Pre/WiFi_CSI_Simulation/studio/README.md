# CSI Studio v0.1.0

用于通信原理课程演示的三维 Wi-Fi CSI 人体运动感知程序。桌面界面、信道计算、检测结果与导出文件共用同一次仿真数据。

## 打开与演示

解压完整程序目录，双击 `CSI Studio.exe`。程序自带 Python、Qt、Three.js 和模型权重，支持离线启动。将整个目录一起复制到汇报电脑，并保留 `_internal` 文件夹。推荐窗口 1600 × 900，可缩放至 1280 × 720。

1. 选择顶部预设场景，点击 **计算仿真**。
2. 播放或拖动底部时间轴，观察人物动作、CSI 波形、检测分数和预测轨道。
3. 切换 AC、AD、BC、BD，展开 **算法对比**，查看原始 / 优化算法的单链路与融合结果。
4. 修改节点或动作后再次计算，通过 **导出** 保存图片、数据或汇报幻灯片。

计算在后台线程完成；播放控件负责同步回放计算结果。状态栏分别显示计算耗时、回放帧和射频参数。

## 编辑

| 控件 | 操作 |
| --- | --- |
| 场景 | 无人 / 有人、房间长宽高、墙面反射、频率、带宽、采样率、SNR、人体回波、丢包率、随机种子、家具参数 |
| 节点 | 点击列表或场景中的节点；拖动设置 XY，属性框设置 XYZ、发射 / 接收、天线数及朝向 |
| 路径 | 进入动作标签，点击“＋ 路径点”后点地面；拖动路径点或编辑坐标 |
| 动作 | 添加走动、停留、挥手；编辑时长、速度、目标点、挥手摆幅 / 频率 / 朝向；支持调整顺序和删除 |
| 时间轴 | 点击定位、拖动播放头；拖动真值动作块的右边界修改时长 |
| 视角 | 鼠标左键拖动空白区域旋转，右键平移，滚轮缩放；按钮切换 3D / 俯视 |
| 阈值 | 拖动分数图的虚线；复用当前 CSI 重新生成检测结果与指标 |
| 快捷键 | 空格播放 / 暂停，Ctrl+S 保存场景，Ctrl+O 打开场景 |

默认两发两收，共 AC、AD、BC、BD 四条链路。节点总数可在 2–4 个之间编辑，每个场景至少包含一个发射节点和一个接收节点。多天线采用半波长间距均匀线阵的等效增益，朝向参与阵列增益计算。

人员真值使用“走动 / 停留 / 挥手”，预测使用“运动 / 静止”。无人和有人停留的真值均为静止。灰蓝条表示检出运动，红色斜线表示漏检，琥珀描边表示误报。

## 三维信道与人体

默认房间为 6 × 5 × 3 m，2.462 GHz / 20 MHz，100 Hz，56 个有效子载波，SNR 25 dB。程序根据三维坐标求取直达路径、六个边界面的一次镜像反射、8 个固定随机散射点、每件家具的 4 个等效散射点，以及躯干、左手、右手的动态路径。各路径通过长度、衰减和复相位叠加，再加入噪声、设备相位误差和丢包。

场景开始前生成 10 s 静态校准段。随机种子相同、配置相同，可复现相同 CSI；修改节点高度或家具反射会改变信道。第一菲涅尔椭球由当前链路距离和波长计算，作为几何展示层。

人体采用共用关节模型：肩部随躯干平移和转向，上臂与前臂长度各 0.30 m，通过双骨骼逆运动学连接到手部。抬手、挥手和收手连续过渡；手部目标受臂展约束。摆幅表示期望的横向目标振幅，实际轨迹同时满足臂长约束。动画中手球中心与动态散射点使用同一坐标。

## 算法与评价

两套算法读取同一份 CSI。原始模型使用 16 个特征，优化模型使用 40 个特征，包含 0.2 / 0.4 / 1 s 多尺度统计量。使用尾随窗口，每 0.2 s 更新检测。链路质量决定融合权重，有效性检查保留丢包和采样间隔约束。

随包提供前期 `core_optimized_20261104_v1` 实验的冻结模型及校准参数，分别支持 50 / 100 Hz。权重训练来源为前期二维仿真；当前程序在三维信道上直接计算其预测。界面中的数值取自当前配置，导出数据保留模型哈希和来源。

显示分数为 `e / (e + 原校准阈值)`，其中 `e = -log(1-p)`；显示阈值 0.50 对应原校准工作点。最终状态包含迟滞和持续性规则，因此分数越阈后的状态转换存在相应延迟。

F1、精确率、召回率、误报率按有效的 5 Hz 决策点计算；误报率为 FP / (FP + TN)。平均延迟按连续运动事件起点到首次正确检出的时差计算，漏检事件通过召回率、时间轴及导出指标中的检出事件数体现。链路数显示当前时刻通过有效性检查的链路数。分母为零的指标显示“—”。

CSI 幅度显示静态校准归一化后的子载波 +8；相位视图使用同一子载波并去除每包的线性子载波相位。子载波热力图覆盖全部 56 个子载波，时频谱来自当前链路幅度。图表和轨道跟随同一时间游标。

## 文件

- 场景 JSON：全部可编辑参数、节点、路径和动作，可重新打开。
- 图片 PNG：当前完整界面截图。
- 数据 ZIP：`project.json`、`metadata.json`、`metrics.json`、`decisions.csv`、`observations.npz`。NPZ 包含原始复数 CSI、包时间 / 序号 / 有效标记、姿态散射点和决策真值。
- 汇报 PPTX：当前界面、可编辑的四组算法指标图、可编辑的场景与动作表。
- `licenses` 与 `runtime-versions.json`：随包运行库的许可文件与版本信息。

## 源码运行与检查

在 `WiFi_CSI_Simulation` 项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-studio.txt
.\.venv\Scripts\python.exe run_studio.py
.\.venv\Scripts\python.exe -m pytest tests/test_studio.py -q
.\.venv\Scripts\python.exe run_studio.py --smoke validation/studio_manual
.\.venv\Scripts\python.exe build_studio.py
```

姿态一致性测试通过本机 Node.js 执行前端数学模块；日常运行使用随包的 Qt WebEngine。核心文件：`project.py` 场景格式、`geometry.py` 信道与姿态、`engine.py` 检测计算、`desktop.py` 桌面桥接、`web/` 三维界面、`exporting.py` 文件导出。
